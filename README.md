# 工程材料及热处理C · 高效记忆刷题台

一个**单文件、零依赖、纯前端**的复习刷题页面：打开即用，进度存在本机浏览器里。

> 在线访问：**https://<你的用户名>.github.io/eng-mat-review/**

## 功能

- **考点挖空背诵** —— 正文里的关键术语默认用遮罩盖住，点一下显示答案，适合「先回忆再看」的主动记忆法。
- **20 个牌号翻转卡** —— 正反面翻转记忆材料牌号的成分、性能与典型用途。
- **48 道真题自测** —— 判断题 + 选择题，做完立刻给对错和解析。
- **自动错题本** —— 答错的题自动归档，支持反复重做，直到清空。

## 部署方式

整个站点只有一个 `index.html`（外加一个空的 `.nojekyll`），没有构建步骤、没有 npm 依赖、不请求任何外部 CDN，断网也能打开。

托管在 GitHub Pages：`main` 分支根目录，构建方式 `Deploy from a branch`。

## 本地使用

直接双击 `index.html` 即可在浏览器打开（`file://` 协议下功能完整，但无法分享给别人）。

手机端建议在浏览器里「添加到主屏幕」，可全屏运行、无地址栏。

## 自定义题库

所有内容集中在 `index.html` 顶部的 `STUDY_DATA` 对象里：

```js
const STUDY_DATA = {
  chapters: [...],      // 章节知识点
  flashcards: [...],    // 翻转卡
  tfQuestions: [...],   // 判断题
  mcQuestions: [...]    // 选择题
};
```

正文明细里用 `[[文字]]` 表示「要挖空遮罩的内容」，`<b>文字</b>` 表示加粗。换课程时记得把 `localStorage` 键名前缀 `eng_mat_2026_` 一起改掉，避免和本页数据串。

## 隐私

页面上没有任何网络请求，学习进度、错题记录只写入本机 `localStorage`，不上传、不同步、不进后台。
